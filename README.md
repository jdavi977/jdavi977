# Hi, I'm John 👋

I'm a Bachelor of Computer Information Systems student at Mount Royal University in Calgary, graduating this December 🎓

### 📊 Why I build with data
Everything we do creates data: how we sleep, how stressed we are, which habits stick and which ones fade. Most of it goes unnoticed. I believe that tracking and visualizing it helps us understand ourselves better and shows us where we can improve.

That's what I focus on: creating and contributing to apps that turn everyday data into insight, so I can learn how technology can help improve people's lives.

### 🛠️ Some things I am working on!
- **[apple_health_stress_pipeline](https://github.com/jdavi977/apple_health_stress_pipeline)**: a data pipeline that analyzes Apple Health exports to understand stress
- **[habit_heatmap_tracking](https://github.com/jdavi977/habit_heatmap_tracking)**: visualizes habit consistency over time as a heatmap
- **[habit-rpg](https://github.com/jdavi977/habit-rpg)**: turns building habits into an RPG
- **Open source:** contributor to [yt](https://github.com/yt-project/yt), a Python toolkit for analyzing and visualizing volumetric data
